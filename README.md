# 🎰 LottoScope (로또스코프)

> **대한민국 역대 로또 6/45 1등 당첨 빅데이터 기반 AI 통계·확률 번호 제안 및 근거 브리핑 서비스**

1회부터 최신 회차(1,240회)까지의 공식 1등 당첨 데이터를 전수 분석하여, 통계적 정규분포와 확률적 가중치 모델에 기반한 번호 조합을 제안하고 **"왜 이 번호인가?"**에 대한 시각적 리포트를 제공하는 서비스입니다.

---

## ✨ 핵심 기능

1. **No-DB 초경량 아키텍처**
   - 1,240회 전체 데이터셋(약 320KB)을 클라이언트 인메모리(JSON)에서 처리하여 **0ms 즉각 연산**과 **서버 호스팅 비용 0원**을 실현.
2. **매주 토요일 자동 업데이트 파이프라인 (GitHub Actions)**
   - 매주 토요일 21:15 KST(동행복권 공식 추첨 직후) GitHub Actions 스케줄러가 자동으로 신규 회차 데이터를 수집하고 커밋/재배포.
3. **3가지 맞춤형 통계 추천 모드**
   - 🌟 **황금 밸런스형**: 역대 1등 데이터의 정규분포 최중심점(총합 100~175, 홀짝 3:3, AC값 8 이상)에 수렴하는 AI 정석 조합.
   - 🔥 **상승세 트렌드형**: 최근 10주간 출현 빈도가 높은 Hot 번호들의 기세를 집중 반영.
   - ❄️ **회귀 확률형**: 대수의 법칙에 따라 장기간 미출현하여 확률적 반등 주기에 도달한 Cold 번호 중심 조합.
4. **시각적 추천 근거 리포트 (Reasoning Engine)**
   - 6각형 레이더 차트 (총합, 홀짝, 고저, AC 복잡도, 연번 통제, 누적 빈도)
   - 각 번호별 통계 스토리 뱃지 (`#15주미출현반등`, `#역대최다출현TOP5`, `#최근10주간3회출현Hot`)
5. **빅데이터 분석 랩 & 역대 당첨 백테스터**
   - 1~45번 전체 출현 빈도수 인터랙티브 바 차트 및 Hot/Cold 트렌드 분석
   - 내가 고른 번호가 과거 1회부터 현재까지 1~5등에 당첨된 적이 있는지 즉시 시뮬레이션

## 🚀 빠른 시작 가이드 (로컬 실행)

```bash
# 1. 의존성 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev
# 브라우저에서 http://localhost:5173 접속

# 3. 프로덕션 빌드
npm run build
```

## 🔄 데이터 수집 및 자동 갱신 스크립트

- **수동 데이터 갱신**:
  ```bash
  node scripts/update_weekly.js
  ```
- **전회차 데이터 재수집**:
  ```bash
  node scripts/fetch_all_lotto.js
  ```
- **GitHub Actions 자동 갱신 워크플로우**:
  - 파일 위치: `.github/workflows/update_lotto.yml`
  - 매주 토요일 21:15 KST, 21:45 KST 자동 실행되어 변경사항 발생 시 자동 Git Push.
